# Networkwalks Internship – Week 2: Reconnaissance

## Project Overview

This repository documents my practical learning experience during Week 2 of my Cybersecurity Internship at Networkwalks.

The focus of this week's exercise was **Reconnaissance**, one of the fundamental phases of penetration testing.

The objective was to understand how information about a target's digital presence and network infrastructure can be gathered and analysed during a security assessment.

## Objectives

- Understand the importance of reconnaissance in penetration testing.
- Gather domain and DNS information.
- Identify web technologies and security infrastructure.
- Examine HTTP responses.
- Discover live hosts on a local network.
- Identify IP and MAC addresses.
- Document findings from reconnaissance activities.

## Why Reconnaissance Matters in Cybersecurity

Reconnaissance is an important phase of penetration testing because it helps security professionals understand the environment they are assessing before proceeding with deeper security testing.

It helps identify exposed services, available information, network devices and potential areas that may require further security assessment.

Without proper reconnaissance, a penetration tester may overlook important information or approach an assessment without understanding the target environment.
